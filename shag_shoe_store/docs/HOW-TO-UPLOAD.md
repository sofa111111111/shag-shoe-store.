# Как работать с материалами

1. Откройте репозиторий GitHub и создайте новый пустой репозиторий, например `shag-shoe-store`.
2. Распакуйте архив проекта и загрузите всё содержимое в корень репозитория.
3. PNG-файлы блок-схем можно вставлять в отчёт Word.
4. Файлы `.drawio` открываются на https://app.diagrams.net/ и предназначены для редактирования.
5. Файлы `.dot` — дополнительные исходники диаграмм Graphviz.
6. После загрузки выполните commit и push.

## Что ещё нужно уточнить в команде
- Добавить ФИО остальных участников, если они есть.
- При необходимости заменить учебное название магазина «Шаг» на утверждённое командой.
- На следующих этапах заполнить папки `db/` и `src/` реальными SQL-скриптами и исходным кодом приложения.

## Важное замечание
Блок-схемы составлены по последовательностям D01–D11 из предоставленного файла `de-modules-function-extract.pdf` и оформлены по памятке `drawio-block-schemes-guide.pdf`. Проектная документация отражает исходное задание; это не готовое работающее приложение.
