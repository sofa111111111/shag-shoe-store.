# Магазин обуви «Шаг»

Учебный проект информационной системы для магазина обуви.

## Назначение
Система предназначена для ведения каталога обуви, контроля остатков на складах и работы с заказами. Пользователи получают доступ к функциям в соответствии со своей ролью.

## Технологический стек
- **Язык программирования:** C#
- **СУБД:** MySQL

## Роли пользователей
- **Гость** — просмотр каталога без поиска, фильтрации и сортировки.
- **Авторизованный клиент** — просмотр каталога.
- **Менеджер** — просмотр каталога с поиском, фильтрацией и сортировкой, просмотр заказов.
- **Администратор** — управление товарами и заказами, включая добавление, редактирование и удаление с проверками прав.
